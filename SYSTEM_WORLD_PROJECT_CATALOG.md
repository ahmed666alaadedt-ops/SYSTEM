# SYSTEM WORLD — Project Catalog

## 1. Purpose

This file is the central catalog for all Godot projects belonging to SYSTEM WORLD.

Its purpose is to:
- Keep track of existing projects and files.
- Prevent duplicate work and accidental deletion.
- Record maps, characters, NPC systems, environments, and 3D assets.
- Track what is implemented, connected, incomplete, or awaiting visual verification.
- Guide future development one project or system at a time.

This catalog does not merge projects or move their files.

## 8. Development Status Definitions

Use these labels for every project and system:

- EXISTS: Files or implementation are present.
- PARTIALLY IMPLEMENTED: Some functionality exists, but completion is not verified.
- CONNECTED: A real code or project connection has been inspected.
- NEEDS CONNECTION: The component exists but its integration is incomplete.
- NEEDS VISUAL AUDIT: Godot inspection is still required.
- VERIFIED COMPLETE: Tested in Godot and confirmed to work as intended.
- NOT FOUND: Confirmed absent after checking all relevant projects and code.

Never label an item VERIFIED COMPLETE based only on its filename or the existence of a script.

---

## 9. Rules for Future Development

1. Preserve all existing projects and files.
2. Never delete or replace an existing system without inspecting its dependencies.
3. Search both Godot projects before declaring an asset or feature missing.
4. Distinguish external 3D models from procedural 3D objects.
5. Distinguish code implementation from a finished visual result.
6. Record every newly created or verified system in this catalog.
7. Complete missing systems one at a time.
8. Keep the official runtime project separate from the 3D preview project unless integration is deliberately planned.
9. Avoid rebuilding systems that already exist.
10. Verify actual behavior in Godot before marking a system complete.
