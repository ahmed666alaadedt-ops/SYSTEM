
# SYSTEM WORLD - Weather Audio

Dynamic weather sound library for all four worlds.

## Weather Sounds

- Light rain.
- Heavy rain.
- Thunder and lightning.
- Strong and gentle wind.
- Storms and hurricanes.
- Snow and blizzards.
- Sandstorms.
- Distant thunder.
- Rain hitting roofs, windows and streets.
- Wind moving through trees and buildings.

## Dynamic Audio Behavior

- Weather sounds change with weather intensity.
- Thunder volume changes according to distance.
- Indoor locations reduce outdoor weather volume.
- Weather transitions should feel natural.
- Day and night ambience can affect the atmosphere.

## Technical Standards

- Preferred format: OGG Vorbis.
- Optimized for Android performance.
- Use original or properly licensed recordings.
