
# SYSTEM WORLD - UI Audio Library

Cinematic interface sound library.

## Buttons
- Button click.
- Button hover.
- Button selection.
- Button confirmation.
- Button cancellation.
- Locked button feedback.

## Menus
- Main menu opening.
- Main menu closing.
- Settings navigation.
- World selection.
- Character selection.
- Inventory opening and closing.

## Notifications
- New mission.
- Mission completed.
- Level up.
- Achievement unlocked.
- New message.
- Friend request.
- Guild invitation.
- Warning and error notifications.

## Special Interface Effects
- SYSTEM awakening.
- Holographic interface activation.
- World portal activation.
- Loading transitions.
- Rare reward discovery.
- Legendary reward announcement.

## Audio Behavior
- Short and clear sounds.
- Avoid excessive repetition.
- Separate UI volume from music and effects.
- Smooth transitions.
- Optimized for mobile devices.

## Technical Standards
- OGG Vorbis preferred.
- Original or properly licensed audio.
