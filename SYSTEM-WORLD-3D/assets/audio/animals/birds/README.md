
# SYSTEM WORLD - Birds Audio Library

Detailed bird sound collection for all four worlds.

## Bird Species
- Sparrows.
- Crows and ravens.
- Eagles.
- Falcons.
- Hawks.
- Pigeons.
- Seagulls.
- Owls.
- Parrots.
- Ducks.
- Nightingales.
- Peacocks.

## Sound Types
- Morning singing.
- Daytime calls.
- Night calls.
- Warning calls.
- Flying and wing flapping.
- Landing and taking off.
- Nest and family sounds.
- Flock communication.

## Environmental Behavior
- Birds react to nearby threats.
- Different species inhabit suitable environments.
- Sound direction and distance must be spatial.
- Bird activity changes with time and weather.
- Avoid repetitive sound loops.

## Technical
- OGG Vorbis preferred.
- Android optimized.
- Original or properly licensed recordings only.
