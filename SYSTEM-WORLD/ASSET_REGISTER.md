## Asset acceptance rules

A new environmental or character asset may be marked production-ready only after all applicable checks pass:

1. Source and licence/attribution are recorded.
2. The asset is present in the canonical runtime project.
3. GLB structure and embedded resources validate.
4. Godot imports it without errors.
5. Materials, scale, orientation, rig and animation are visually reviewed.
6. Collision, navigation and interaction are checked where applicable.
7. LOD, texture sizes, memory and draw-call budgets are reviewed for Android.
8. The asset is connected to the correct world/region system.
9. A reviewer records the exact file path and validation evidence.

Until then, label it as source, prototype, blockout, generated candidate, or pending review. Never count a placeholder as a finished asset.
